# Verbatim to Signal Workbench

Hands-on training tools for MedDRA coding, SMQ retrieval and safety surveillance — the companion workbench to the book *From Verbatim to Signal: MedDRA Coding, SMQs, and Safety Surveillance* by Dr. Hafez Selim, MD, PhD (Selim Medical Press, 2026).

**Live site:** https://abdu94-hash.github.io/verbatim-to-signal-workbench/

Modules: coding trainer, retrieval lab, surveillance calculators, fillable worksheets (19 tools).

Training tool with synthetic data. Not validated software; not for regulatory decisions. Contains no MedDRA terminology. MedDRA® is a registered trademark of ICH. Everything a user types stays in their browser (localStorage).

Static site: no build step. Serve the folder as-is (GitHub Pages from `main` / root).
